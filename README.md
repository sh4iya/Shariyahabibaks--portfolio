# Shariya Habiba K S — Product Designer Portfolio

Static, responsive portfolio ready for Vercel. No build tools, npm install, API keys or environment variables required.

## Publish on Vercel
1. Extract this ZIP.
2. Import the extracted `Shariya_Studio_Portfolio` folder into a GitHub repository (put index.html at repository root).
3. In Vercel, select **Add New → Project**, import the repository, set Framework Preset to **Other**, and leave Build Command empty. Set Output Directory to `.` if prompted.
4. Click **Deploy**. Vercel will provide a public `*.vercel.app` URL.

Alternatively, use Vercel CLI from inside the folder: `npx vercel --prod` (requires your Vercel account and network access).

## Files
- `index.html` — homepage
- `project.html?id=mevia|shipthis|freelance|food` — case studies
- `app.js` — project data and interactions
- `style.css` — responsive styles, animations, accessibility
- `assets/` — actual project imagery

## Publishing checklist
- Verify you have permission to publicly show employer design work.
- Replace or verify personal social links before adding them (none invented).
- Check image legibility on mobile and desktop.
- Add a real resume file and link only after it has been approved.
- The portfolio describes intended benefits as hypotheses, not measured outcomes.
